# Tic Tac Toe game 

## Project Preview
![This is an alt text.](/preview.png "Project banner")

It's a two player game and follows the standard tic-tac-toe rules.

## To run this game from the exe file

**Click to download [exe file](https://github.com/impriyanshusah/Tic_Tac_Toe-python/blob/main/exe/tic_tac_toe)**

## To run this project locally

**Cloning the repositary**  
```
git clone https://github.com/impriyanshusah/Tic_Tac_Toe-python
```  

**Installation**  
```
pip install PyQt5
```

**Running the project**
```
python main.py
```
